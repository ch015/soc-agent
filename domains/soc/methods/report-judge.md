# SOC report judgment method

1. Read the sealed report snapshot and evidence-first review named by the host.
2. Produce bounded report claims with unique keys, typed epistemic status, existing evidence locators, and an exact machine-checkable `evidenceAssertions` locator set.
3. Separate direct observations, supported inferences, and unverified hypotheses.
4. Include material alternatives, counterevidence, coverage limitations, and advisory-only next steps using only permitted non-operational action types.
5. Return only the report judgment schema; do not write or publish artifacts.
