# SOC report verification method

1. Read the sealed snapshot, evidence-first review, and candidate judgment named by the host.
2. Review every claim and advisory-action key exactly once, bind each review to its exact locator set, and challenge assertion mismatches or disproportionate actions.
3. Challenge unsupported certainty, invented entities/counts, ignored counterevidence, and coverage omissions.
4. Set `hold` when a material concern remains. This is an internal draft gate, not publication approval.
5. Return only the report verification schema.
