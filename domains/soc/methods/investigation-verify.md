# SOC investigation verification method

1. Read the sealed snapshot, evidence-first review, and candidate analysis named by the host.
2. Review every claim, hypothesis, and advisory action exactly once and check locator, evidence assertion, prerequisites, limitations, time, subject, direction, query coverage, and action proportionality.
3. Challenge anchoring on labels, severity, urgency, ordering, account type, or timezone.
4. Set `hold` for unsupported conclusions, missing alternatives, or material coverage gaps.
5. Return only the investigation verification schema.
