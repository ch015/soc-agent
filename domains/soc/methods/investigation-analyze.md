# SOC investigation analysis method

1. Read the sealed investigation snapshot and evidence-first review named by the host.
2. Form bounded claims from existing evidence locators, an exact machine-checkable `evidenceAssertions` locator set, and the exact query ledger.
3. Record counterevidence, alternative hypotheses, prerequisites, limitations, and unverified gaps.
4. Use only permitted non-operational action types; do not claim attribution, compromise, malicious intent, or operational authorization without contract-defined support.
5. Return only the investigation analysis schema.
